# Pixel Room
Created by Gianx labs.

A browser-based image pixelator with adjustable 1–512 px blocks, original comparison, and PNG, JPG, WebP and SVG downloads. Images are processed locally, with no server uploads or API keys.

## Upload to Netlify — no coding needed
1. Unzip this project.
2. Open Netlify's manual deployment / drag-and-drop page.
3. Drag the **dist folder** onto the upload area. This folder contains the complete ready-to-use website. Upload the folder itself, not the enclosing pixel-room-project folder.

## Deploy through GitHub
Upload this project's contents to a repository and connect it to Netlify. The included netlify.toml sets the build command to `npm run build` and the publish directory to `dist`.

## Edit and rebuild
Node.js 22 or newer is recommended.

```sh
npm ci
npm run build
```

- `app.js`: image processing, controls and downloads.
- `dist/index.html`: page content and layout.
- `dist/style.css`: styling and responsive layout.
- `dist/app.js` and generated chunks: built browser scripts. Regenerated by the build command.
- `package.json` / `package-lock.json`: dependencies and build settings.
- `netlify.toml`: Netlify deployment settings.

To preview locally, serve `dist` over HTTP; if Python 3 is installed, run `python3 -m http.server 8080 --directory dist` and open http://localhost:8080. Opening index.html directly from disk does not support JavaScript modules reliably.

## Image support and SVG downloads
Common browser image formats are supported, with additional HEIC/HEIF and TIFF decoding. Files are limited to 40 MB and 32 megapixels (maximum 16,384 px per side). Animations and multipage images use one still frame. Camera RAW and PSD files need exporting first.

SVG downloads contain actual coloured vector rectangles, including transparency. For very fine settings producing more than 250,000 blocks, the SVG contains an embedded PNG of the pixelated result to avoid enormous vector files; the interface tells the user when this happens. SVG exports retain the original image dimensions.

Third-party decoding libraries retain their own licences; see `dist/licenses`. HEIC decoder source: https://github.com/hoppergee/heic-to (version 1.5.2). TIFF decoder source: https://github.com/photopea/UTIF.js (version 3.1.0).
